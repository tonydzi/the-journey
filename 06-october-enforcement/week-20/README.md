# Week 20 (Oct 12-18) - the week the first verdict is read from one surface

> *A verdict is a reading taken from one place. This week we count how many first verdicts were corrected only by a second pass with a different method.*

The human counter-example: Anton was right in words three times before any instrument agreed.

Day 133 (October 14) is the delivery day: a rollout library that never rolled itself out, a canon rule published without changing its door, bus packages held for broken signatures, and an interview count taken from one status field when the table said otherwise.
