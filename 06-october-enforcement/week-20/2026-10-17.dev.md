# Day 136 - 2026-10-17: instruments searched the wrong carrier and were blind to their own evidence

Dev-log form.

Defect: instrument `I` answers "is fact F present" by reading carrier `C1`. F actually lives on carrier `C2` (git history, mailbox, foreign repo, CPU counters, executable file vs test file). `I` reports absence with full confidence; the evidence exists the whole time.

Position on the line. 133: fix did not reach the consumer. 134: guard shares substance with the guarded.

135: judge accuracy never measured.

136: judge with correct logic reading the wrong carrier.

## 0. Contract

Before an instrument emits "absent / no copy / not delivered / idle / answered", it prints the carrier it read and the list of carriers where F can live. A count is a measure, not a gate; a binary threshold on a count discards the information that decides the case.

A rule that exists only in instruction text has no door at the point of action.

## 1. Vault backup guard (lighthouse)

Full backup blocked 3 nights: 10-15, 10-16, 10-17. Guard summary each night: delete 482, without recoverable copy 139, additions 57,490. Raw `git status`: 723 (different instrument, different definition of changed).

Root:

- `_recoverable()` does not count git history as a copy. All blobs present in HEAD.
- Threshold binary: 482 >= 50 -> block. No weighting by recoverable share or additions.
- Same root diagnosed 07-23, not fixed.

Adjacent:

- Link janitor 10-16 applied 17 links, no commit; 24 h gap where git-reading instruments saw nothing.
- Applicator rejects HIGH-confidence links by parent folder: 22/39 pairs, then 14, 12, 7 across passes. Criterion unchanged.

## 2. xAI applications

10-04..10-07: 12 confirmations (mailbox) vs 6 rows `status=new` in `jobs.db`. Panel "323 over cap", recount 219. Tests `Ran 22 OK`.

Roots:

- Hardcoded `E:\` path in preflight; missing data -> "allowed" for any url.
- No per-employer cap.
- `build_cache` overwrites duplicates by url; blind to duplicates.

Fix: `run_slice.py`, cap test, `_probe_run_slice_gates.py`.

## 3. Force-push review gate

Bare `git push --force-with-lease` in foreign PRs wiped expected review anchors. 4 cases in family; one PR closed `CHANGES_REQUESTED`. Rule lived only in `/pr-reply` instruction text; no mechanical door at push time.

Fix: hook `force_push_review_gate.py` + test. Rollout 4/8 nodes.

Side root: `deploy_register.py` used `lstrip("./")` (charset strip, not prefix strip); `.claude/` -> `claude/`. Fix: `_suffix_hit` (match path tail).

## 4. Idle MCP reducer

Judged idleness by process age ("old != idle"). Shadow since 10-14, harvest 10-21; 22 human turns, `fails=0`; live dry-run 0 candidates.

Rebuilt on CPU delta between samples. Routine only after harvest. Author-declared weak link: proof carried by unit test + mutant, not a live run.

## 5. contrib-watch
