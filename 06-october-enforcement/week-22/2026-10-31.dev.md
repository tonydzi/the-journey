# Day 150 - 2026-10-31: guards match surface (words, letters, length, names), not meaning

Dev-log form. Assembled from the night retro of the hub's lost sessions: 10 units = 29 sessions; all 10 reached a result, nothing critical abandoned.

Defect: a guard decides on a surface feature (a keyword, literal text equality, a length threshold, a file name) while the property it is meant to protect is semantic (intent, topic, content, count).

Position on the line. 149: status from the wrong layer or the wrong moment. 150: verdict from the wrong feature.

---

## 0. Contract

A guard states which feature it reads and which property it protects. If they differ, the gap is named in the guard's passport.

Keyword match != action. Text inequality != different topic. Length != content.

File name != file contents.

## 1. Hook: report word taken for a session launch

Context: token-spend-watchdog, 4 runs. Yellow alerts reach Telegram, not WhatsApp.

Cause A: unattended session has no WhatsApp tool (rail locked/unavailable).

Cause B: the hook matched a word in the report text as a session launch and cut the message.

Net: yellows go only to chat 03.

Fix (open): tool in the unattended session, or send by script; hook must distinguish a report mentioning a launch from a launch.

## 2. Order duplicate check blind across languages

Context: DR on free tiers. dr_start.py, test 4/4. Same order also appeared at Codex; the session removed the duplicate itself.

Cause: duplicate check compares order text. Same topic in two languages = two distinct strings = no duplicate. Check stays green and is literally correct.

Fix (open): compare topics, not strings.

## 3. File name lies, rename blocked

Retro file named "...62-sessii"; contents: 29 sessions.

Rename blocked: mark-done references the file by name. Renaming breaks the reference.

Resolution: name kept on purpose; correction note in the body with the real count. Any name-based counter would report 62.

## 4. Content miner: length threshold admits noise

10-31 scan: 409 sessions; top 30 all noise (skill exams). Admitted by length, not content.

Third case in a row, counting from 10-25.

Workaround: prefix filter + limit.

Root (not fixed): limit applied before the filter; the limit truncates the top before noise is removed. Filter must run before the limit.

## 7. Patterns

P1. Mention vs act: a hook that fires on a keyword must not fire on report or quoted text. Match on the act (tool call, process start), not on its description.

P2. Topic identity: duplicate detection over free text needs a language-independent key (normalized topic, translation, embedding). Literal inequality proves only that strings differ.

P3. Referenced names are frozen: when another component references a file by name, a wrong name is corrected in the body, not by rename. Name-based counters must read contents.

P4. Filter before limit: apply semantic or prefix filters before truncation; a limit applied first lets noise fill the window.

P5. Length is a proxy: a length threshold admits any long text. Pair it with a content filter, or name the proxy in the guard's passport.

P6. Unattended tool surface: a routine that delivers through a channel must verify the channel tool exists in the unattended session, or fall back to a script.
