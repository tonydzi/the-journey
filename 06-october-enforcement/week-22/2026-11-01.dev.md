# Day 151 - 2026-11-01: shared files with many writers converge on the last copy, not the right one

Dev-log form. No canon beats; assembled from about 38 retros.

Defect: a file that is shared in meaning has several writers and no single source. Conflict resolution is implicit: whoever writes last wins. "Newer" is inferred from arrival order or mtime instead of a version carried by the content.

Position on the line. 149: status from the wrong moment. 150: verdict from the wrong feature.

151: truth from the wrong writer.

## 0. Contract

A shared file has one source and one write door. Copies are derived, never edited in place.

"Newer" = version inside the file. mtime, arrival order, sync time != version.

A parcel carries a patch or a versioned artifact; a whole-file parcel must refuse to downgrade.

## 1. approval.py: unsynced per-node forks

Context: lives in each node's scripts folder; folder not synced; each node had a fork.

Problem: node-to-node copy of a "fresher" version dropped the `chat` command. Test red for 5 days.

Cause: no single source; plus unknown command exited 0, so live calls reported success.

Fix: one version (md5 a73823ce) via installer; 9 tests + 28 checks; 4 builds. Live on running nodes; 4 nodes offline; 1 laptop fork not merged.

## 2. deploy_register.py: whole-file parcel erases fixes

Context: 3 live versions.

Side defect: parcel without `--tier` silently became manual. Gate on 8 nodes, applied on 5; 3 colleagues' nodes dead.

## 3. Parcel courier: Errno 9 and mtime as "newer"

Problem A: Errno 9 on Windows; homemade installer called os.fsync on a descriptor opened "rb".

Problem B: "newer" judged by file mtime. Copy/sync touches mtime; an old version looks newer.

Fix: courier 2.0.1. Version instead of mtime; channel chosen by bytes; read-only target. 44 checks; mutants 22/22; real cases 1 of 4219 files.

Live on 3 nodes, 2 offline.

## 7. Patterns

P1. One source, one door: a file shared in meaning gets an installer or owner; local edits are drift.

P2. Version in content: compare versions carried by the file; mtime is transport metadata.

P3. Patch over snapshot: a whole-file parcel encodes everything known at send time and overwrites everything learned later; refuse downgrade.

P4. Unknown command = nonzero: a CLI that exits 0 on unknown input hides a lost feature behind green calls.

P5. Every shared-file fix rides a parcel: an unparcelled fix is erased by the next parcel.

P6. Fold needs a single writer: compaction of a many-writer file decays back; fix ownership, not size.

P7. Fresh sample != representative: liveness from the 10 newest items repeats the same error at a different layer.
