# Day 104 - 2026-09-15: a self-referential check cannot fail, and therefore proves nothing

Dev-log form. Written six days late; the reason is documented in Day 108 and Day 109 rather than hidden.

Day theme: five independent systems were verified against themselves. In each case the verification was performed carefully and returned normal, and in each case the underlying state was broken. A sixth case is the mirror: a correctly working ranker validated against a criterion that was never validated against anything.

---

## 1. Config confirmed the model; runtime ran a different one

**Problem.** A voice-rail session ran on the cheap model while the creation request declared the expensive one. The server acknowledged the declared field.

**Escalation path that failed.** The human reported degraded quality by ear. The agent refuted the report, citing `config.model` from the same request. The instrument under suspicion was used as the evidence clearing it.

**Evidence that settled it.** Transcript: 59 turns on the cheap model before a manual `/model` switch, 220 turns on the declared model after.

**Cause.** The spawn worker never reads `config.model` from the request; it falls back to the settings default, which resolves to the cheap model.

**Fix.** Model pinned via environment for the receiving process. Regression suite of 22 checks.

**Pattern.** A configuration field is a record of a request, not an observation of a runtime. Server acknowledgement confirms receipt of an intent. State must be measured at the consumer's output.

## 2. Research gate counted the echo of our own prompt as the rail's answer

**Problem.** A research order was closed as fulfilled by a rail that had returned no answer.

**Evidence.** ~5,872 bytes counted as a finding were the page echoing our own submitted prompt back at us.

**Rejected fix.** Detecting the vendor's sign-in wall. That patches one instance of a general failure.

**Applied fix.** The measurement itself: subtract the order text from the response before applying length thresholds.

**Guard.** 8/8 tests, demonstrated red against the broken code first.

**Pattern.** Any gate that measures volume of returned content must exclude content it supplied. Otherwise the loudest possible "success" is a perfect echo.

---

## 3. Optimiser gate compared the publisher against himself

**Problem.** The nightly optimiser of the main rules file did nothing for four consecutive nights. No error was raised; the routine started, evaluated, declined to write, and exited.

**Cause.** The pre-write gate asks whether the current publisher holds canon. On the publishing node that comparison is reflexive and always true, and the true branch was wired to "do not write".

**Impact.** File reached 119,592 bytes against a hard ceiling of 120,000. Remaining margin: 408 bytes before the always-loaded rulebook stops loading in full.

**Fix.** The publisher holds canon by definition; the version is read from the header version line instead of an identity comparison.

**Post-fix.** 115,950 bytes, margin 4,050.

**Pattern.** A reflexive comparison in a gate condition yields a constant. A gate whose condition is constant is not a gate, and it fails silently because declining to act raises nothing.

## 4. Three negative verdicts issued from a single vantage point

All three on the same day, all three refuted the same day.

| claim | basis | reality |
|---|---|---|
| "we have no report with numbers" | none; asserted from memory | session-exit hook showed metrics exist |
| "nobody reads the screen layer" | grep over one surface | 10 skills read it; demand ~1 call / 30 days |
| "there is no local calendar rail" | one OAuth token | sweep found 5 surfaces |

**Consequence of the third.** Interview invitations reached the mailbox and the vacancy database but not the human's calendar. First call began 8 h 45 m after he asked about it.

**Pattern.** An existing rule ("empty from one place is not a no; check all of them") was violated three times in 24 hours. A rule that is known and not wired into a call site does not constrain behaviour. Scope of a search is dropped at the first hop, converting a partial negative into a universal one.

## 5. Cure with zero callers beside an honest alarm

**Problem.** Sync divergence alarm read 48.6 days against a threshold of 3. The alarm was correct and continuously visible.

**Cause.** `resolve_conflicts.py` existed, worked, and had zero callers for 73 days. The rule about alarms without owners has existed since 2026-07-04.

**Four roots closed on the fifteenth.**

1. Sweeper returned exit 0 unconditionally; now returns its own honest code.
2. Lock TTL reduced from 1800 s to 240 s.
3. Breakage counter displayed "1 of 3" where six dated cases existed.
4. Dedup paradox in class attribution.

**Guard.** 36 tests green, rolled to 5 nodes.

**Related instance, same day.** Provenance ledger: 227 of 234 lines were written bypassing the only sanctioned door. Third dated case.

**Pattern.** Detection and remediation are separate wires. A remedy with no caller leaves detection running indefinitely as pure cost.

## 6. Leak recurrence 11 days after symptom cleanup

**Problem.** An OAuth token found in transcript files on 2026-09-04 (18 files cleaned) reappeared on 2026-09-15 in 5 files, 11 occurrences.

**Cause.** The cleanup targeted files. The archiver writing transcripts without a secret filter was untouched, and the key was not rotated.

**Status.** Sixth dated case of class `secret-outside-store`.

**Pattern.** Cleaning instances of a leak without rotating the credential and filtering the writer buys exactly one cycle of the producing process.

## 7. Counter-example: a watcher that lied in our favour

**Problem.** The debt watcher reported 53 outstanding replies owed by us.

**Reality after review.** 4 bots, 25 foreign threads where the ball is not ours. Genuine: 15.

**Fix.** Explicit `mentions_us` field rather than presence in a thread.

**Pattern.** Instruments that overstate our workload are detected last, because an inflated backlog reads as diligence rather than as a defect.

## 8. Silent stops with no watchdog

- Screen recording layer stopped twice in two days: disk threshold, then a crash with no auto-restart. 36 hours lost. Detected by a human. Watchdog still not built; recorded as an open debt. Layer at 38.6 GB, +1.5 GB/day without cleanup, 36.7M OCR rows.
- Vault janitor on the far node produced nothing useful for five nights; last live run 2026-09-10. The node, scheduler and routine were all alive.
- Two Tier-2 decision requests about the same leaked credential aged 4-5 days in the queue with no owner and no card.

**Pattern.** Three separate silent-stop instances in one day, none caught by automation. This is the same family that Day 106 will document at cluster scale.

## 9. Mirror case: a correct ranker against an unvalidated criterion

**Observation.** The robot selecting external contribution targets ranked tasks correctly against its configured relevance criterion, with no faults.

**Defect.** The criterion classified second-brain work, semantic search and vector stores as "adjacent", excluding them from the top. Those are the operator's primary areas of expertise.

**Named areas (explicit, from the operator).** Second brain, machine-to-machine links, consensus, outbound, leads, CRM, agents, fleet.

**Why invisible.** The ranker never erred. Nothing in the loop compared the criterion against an external definition of expertise.

**Pattern.** A correctly executing component validated only against its own configuration is a self-referential check at the specification level. The failure surfaces as months of correct work aimed at the wrong target.

## Transferable rules

1. Never verify a disputed reading with the instrument under dispute. The refutation must originate outside it: consumer output, transcript, independent probe.
2. A configuration field describes intent. Runtime state is only observable at the consumer.
3. Exclude self-supplied content before measuring returned volume. An echo is the highest-scoring possible false positive.
4. Reflexive comparisons inside gate conditions produce constants. Audit any gate whose condition can compare an entity with itself.
5. A negative from a single surface must carry its scope. Strip the scope and a partial no becomes a universal no in one hop.
6. Detection and remediation need an explicit wire. Ship a caller with every cure, or the alarm is pure recurring cost.
7. Rotate the credential and filter the writer. Cleaning files buys one cycle.
8. Validate criteria, not only the components that apply them. A correct ranker against a wrong criterion is the most expensive failure mode available, because it never raises anything.
