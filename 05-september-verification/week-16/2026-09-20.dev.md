# Day 109 - 2026-09-20: a correct local verdict terminates the global investigation

Dev-log form. One pattern in five instances. Each instance has a step that was locally correct and globally terminal.

The unifying failure mode of the day: an actor is asked a narrow question, answers it correctly, and the correct answer is indistinguishable from "nothing to escalate". No error is raised, no watchdog fires, no journal line is written, because nothing went wrong at any single step.

---

## 1. Jammed spool: four daily digests undelivered for four days

**Problem.** The daily outbound report did not reach any consumer for four consecutive days (Sep 16-19). Item count in that report moved from 482 to 512 while it was invisible.

**Observation.** `_outbox_undelivered.jsonl` held four harvest digests of 29,000-31,000 characters each. The transport limit is 4,096 characters.

**Cause.** Two layers.

Layer one: the producer had no size contract with the transport. A digest that grows with the backlog will exceed any fixed message limit eventually, and nothing was checking.

Layer two, the expensive one: the stuck item printed its error on every unrelated send. Seven distinct sessions observed that error.

Each compared it against its own payload, correctly concluded "this ping is not mine", and proceeded. The local classification was true in 7 of 7 cases.

**Why no escalation.** "Not mine" answers *must I repair this now*. The needed question was *does an owner for this exist*. The second question belongs to no session's task boundary, so it is never asked, and asking it costs a context switch that no rule requires.

**Status.** Root found, not fixed. Card filed at P0, digger queued.

**Pattern.** An error surfaced in a shared channel, correctly attributed away by every observer, is functionally identical to a silent error. Attribution is not escalation.

## 2. A question carried to the human for seven days while the answer was in canon

**Problem.** An ask containing an ATS form field ("country where you currently reside") sat in the queue from Sep 13 to Sep 20. Three consecutive shifts escalated it to the human as "canon does not know".

**Cause.** Canon held the correct answer the entire time. The defect was in matching: the closed option list spells the country as a two-letter code; the canonical answer emitted the full name as its single candidate; the matcher correctly returned no match.

That honest mechanical no-match was then re-labelled one level up as a knowledge gap.

**Fix.** `ask_gate.py`. Before assembling any "teach me to answer this" list, classify each field into three buckets:

- `ENGINE` - the answer exists, the form rejected its form. Repair the matcher or the option normalisation.
- `CANON-GAP` - no rule exists, but the fact is present in memory or playbook. Write the rule.
- `ASK` - the answer exists nowhere. The only lawful question to a human.

The gate prints the canonical answer next to the field, so the repair target is visible without a human round trip. Deliberately biased toward `ASK`: a false question costs one report line, a false "I will handle it" costs a lost application.

**Guard.** `_test_ask_gate.py`.

**Pattern.** A question put to a human is a claim with the same proof obligation as the word "done". It requires a second pass by a different method before it is issued, not after it is answered.

## 3. A guess recorded as a finding, load-bearing for six days

**Problem.** The Sep 14 shift recorded that the country option was absent from the closed list. A live probe on Sep 20 found it present.

**Cause.** The distinction between "I enumerated the list and the option is absent" and "I did not find the option" was not preserved in the record. Without the hedge, downstream shifts treated it as enumerated fact and searched elsewhere.

**Pattern.** A cause is a claim of the same rank as a conclusion. An unhedged negative from a non-exhaustive search propagates as an exhaustive one, because the scope of a finding is dropped at the first hop.

## 4. Class counter errs in both directions

**Problem.** The breakage journal folded four dated occurrences of the same spool defect into a single case. The escalation threshold is three.

**Counter-observation, same week.** On Sep 16, on another node, one defect was filed under five different class names across three days. None of the five reached three either.

**Cause.** The counter deduplicates and counts by class **name**. The threshold is defined over the **family** of the defect. The name is assigned by whoever writes the line, at a moment when they do not yet know it is a repeat.

**Consequence.** The instrument built to detect recurrence is the most reliable way to miss it: it merges distinct occurrences under one name and splits identical occurrences across many.

**Pattern.** Any counter that gates an escalation must be keyed by something the writer cannot choose at write time. Free-text class names are chosen by the least-informed party at the least-informed moment.

## 5. Test red from a hardcoded date, green and lying before that

**Problem.** `_test_brain_temporal.py` turned red on Sep 20.

**Cause.** The fixture pins `BRAIN_TEMPORAL_TODAY=2026-09-18`. Once the real date passed Sep 18, `ORDER BY valid_from` inverted relative to the fixture's assumption. The product was not involved.

**Prior state.** For two days before the eighteenth the test was green while asserting an ordering that depended on a date it held internally.

**Status.** Second dated occurrence of the class. Per our own law, a mechanism is built on the third; recorded, not repaired.

**Pattern.** A fixture that hardcodes "today" converts a passing test into a time bomb with a known detonation date and no owner watching that date.

## 6. Stopped pipe reads as empty input

**Problem.** Chat distillation produced nothing new for four months and this read as "no valuable chats".

**Evidence.** 474 notes carry a `distilled_date`; all are in 2026-05. Scoring above threshold by month: March 157, May 7, June 1, then zero.

**Cause.** Distillation ran as a one-off campaign in May. Scoring of new material stopped with it. No instrument distinguished "the scorer found nothing" from "the scorer did not run".

**Measurement after the fix.** `distill_queue.py` counted 4,469 chats in queue, 1,909 above threshold.

**Adjacent work, same root.** `brain_evidence.py` - SQLite FTS5 over the entire raw layer, 193,371 files indexed in 163 s, 1.3 GB database, machine-local. The curated dense index deliberately excludes conversations to keep them from drowning concepts; the evidence lane specified in the same decision had never been built, so ~1.5 GB of chats were unreachable. Six test cases, red on two mutations.

**Status.** Production run of the drip blocked by a harness gate, awaiting explicit permission. Named as a debt, not reported as a finished pipe.

**Pattern.** Absence of output from a stopped stage is observationally identical to absence of input. Any stage whose emptiness is meaningful must emit a heartbeat of *ran* separately from a heartbeat of *produced*.

## 7. Written and never sent: 121 follow-up drafts

**Problem.** Post-call follow-ups are generated and held in `drafted` state indefinitely.

**Cause.** A June 22 SOP requires a human plus sign before sending. That SOP predates two later rules (Aug 5: a reply to a lead does not wait for a human; Sep 13: routines decide reversible forks themselves) and was never reconciled with them.

**Constraint.** Releasing the accumulated batch at once is a mass mailing, which is Tier-2 and belongs to the human by standing rule. The conflict is therefore real, not a bug.

**Status.** Open, escalated as a decision rather than silently resolved either way.

**Pattern.** When a newer general rule supersedes an older specific SOP, nothing reconciles them automatically. The older SOP keeps executing correctly and keeps producing a growing pile of correct non-actions.

## 8. Call-to-CRM pipe

**Built.** Distribution of meeting transcripts onto lead cards, a call package with extracted promises, a weekly routine, a storefront. Data in its own database rather than the 1.5 GB leads store, joined by lead slug, with the leads store opened read-only.

**Measured at birth.** 748 meetings (164 internal), 244 bound to leads, 146 leads with calls, 887 promises (289 ours, 598 theirs), 111 people with a call and no CRM card.

**Pattern.** Two rails had been pulling transcripts into the vault for months while the consumer that needed them held no table for them. Delivery to a store is not delivery to a consumer.

## 9. Counter-example: an expired verdict caught before it was inherited

**Prior state.** On 2026-08-06 we recorded that a routine's `model` frontmatter field is ignored by the application.

**Refutation.** Canary probe file, line 2: `2026-09-10 ... frontmatter_model=sonnet actual=claude-sonnet-5`. Line 1 of the same file, dated 2026-08-06, shows a different actual under the same declared field.

**Conclusion.** The application began honouring the field between those dates. The original note had explicitly flagged this as possible.

**Outcome.** Moving a grunt routine to a cheaper model now costs one frontmatter line. First converted: the nightly job-scan routine.

**Caveat stated.** Single-run proof. A second run of the converted routine must confirm by fact; until then this is strong evidence, not law.

**Pattern.** A negative capability verdict has a shelf life equal to the release cadence of the system it describes. Verdicts about a moving platform must carry a recheck date.

## Transferable rules

1. Attribution is not escalation. An error correctly identified as somebody else's by every observer behaves exactly like a silent error. Shared-channel errors need an owner lookup, not only an owner check.
2. A question put to a human is a claim. Classify into engine defect, missing rule, and genuine unknown before issuing it; only the third is lawful.
3. Key escalation counters by defect family, never by a free-text name chosen by the writer at write time.
4. Never hardcode "today" in a fixture. If you must, assert on the pin itself so the test fails loudly at the pin rather than quietly changing meaning.
5. Emit *ran* separately from *produced*. Otherwise a stopped stage and an empty input are the same observation.
6. When a general rule supersedes a specific SOP, reconcile explicitly. Unreconciled SOPs keep executing correctly forever.
7. Negative capability verdicts expire. Attach a recheck date to any "X is not supported".
