# Day 152 - 2026-11-02: an order is evaluated against the world at write time, executed against the world at rise time

Dev-log form. Assembled from about 65 retros; no canon beats for the day.

Defect: an order (seed, brief, schedule claim, negative claim) encodes a precondition true at write time. The executor reads it later and does not recheck the precondition; the world has moved (task state, newer order, newer pause, newly built artifact).

Position on the line. 151: newest copy of a shared file wins. 152: the oldest condition inside an order wins over the newer world.

## 0. Contract

An order carries the timestamp of the world it describes. The executor rechecks every precondition at execution time and compares the order date with any newer order, pause or state change on the same object.

Negative claims ("none exists", "impossible") carry a timestamp and expire.

## 8. Patterns

P1. Seed by state: a rerun seed is generated from the target's current state (enabled, disabled, one-shot) and revalidated by the executor before acting.

P2. Order freshness: before executing, query for any newer order, pause or decision on the same object; the newest wins.

P3. Briefs carry provenance: a number in a brief carries who measured it and when; the executor remeasures before planning.

P4. Negative claims expire: "none", "impossible", "never existed" carry a timestamp and a recheck path (search, door listing).

P5. Quotes carry clocks: a quote without a timestamp cannot be combined with another quote.

P6. Journal rows close with the fix: a fix without closing its debt row re-triggers the queue; a sensor confirms the fix is in place.

P7. Self-comparing tests are green forever: a test must read the measured cadence, not the constant under test.

P8. Signatures bind bytes: a signature over metadata alone allows cargo substitution.
