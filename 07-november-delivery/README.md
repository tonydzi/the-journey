# 07 - November: Delivery

> *A door at the point of action decides whether the thing may pass. November asks the next question: did it arrive where it is consumed, and was the world still the same when it got there?*

October ended with a rule that holds only when a door stands at the point of action. Words in a canon did not hold the hand; a gate on the execution path did.

November takes the next step. A door can pass the right thing and it can still fail to land: the fix stands on one node of eight, the parcel is registered and not applied, the order reaches its executor after the world has changed.

So November is the month of delivery. A thing counts as done when its consumer reads it, at the moment of use, in the world as it is then.
