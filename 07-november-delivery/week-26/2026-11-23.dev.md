## 9. Patterns

P1. A fallback that produces normal-looking output is a cost leak. Default to refusal with a named reason; keep the old path behind an explicit flag.

P2. A refusal needs a reader. A counter nobody reads turns a loud refusal back into a silent one.

P3. On diverged copies push an anchored patch: apply a chunk only on an exact single match; one miss leaves the file untouched.

P4. "Not found by one key" is not absence. List the archive contents and search by a second key (title) before "missing".

P5. A closed-group draft never enters a derived artifact; use the public version.

P6. An incomplete panel is reported as incomplete; the limit is not raised silently.

P7. "Connected" of one process is not success of another. Name process, transport, registration and time; a narrow log window does not prove absence.

P8. `done` means processed and delivered; completeness is a separate claim. Empty parts are flagged; exact matches precede broad ones.

P9. Delivered is not applied while old writers stay open. Compare a growing file by exact byte count at the author at measurement time.

P10. A queue record is not an artifact; uploaded document count is not completeness. A missing selector (`-s`) silently widens to all sources.

P11. A move copies everything; filters live in the sync pipe.

P12. Measure the suspect before cutting it; the real cost was startup load (52.6%), not messenger tools (0.8%).

P13. A help flag must not have side effects.
