## 5. Patterns

P1. A collector run on a peer must not include itself as the hub. The peer list names the real hub and excludes the local node.

P2. A bucket reading carries its age. A 0% from a reading 514 minutes old is a stale reading.

P3. A second check uses another method with a refutation threshold set before the comparison.

P4. An open SQLite with WAL is moved by an atomic directory swap on the same disk. Copy plus rename loses the WAL tail.

P5. File mtime does not prove a finished build. The completion signal must be written by the build itself.

P6. A replacement refuses a missing source root before touching the old artifact.

P7. A timeout without a whole-run measurement is an unproven cause. A slice benchmark does not stand in for the full run.

P8. A fleet check must run on every OS it claims. Shell-specific checks need a portable type.

P9. A report states the denominator: "6/6" of responding nodes is 6 of 9 of the fleet.

P10. A shared first-wins request is wrong for a per-node check. Each node gets its own request.

P11. Timestamps written by a node clock are normalised before ranking against world time.

P12. A foreign copy overrides a live local file only when it is longer and newer. Session continuation across nodes is in the test set.

P13. Before stating a node's sharing state, read the live API. A config file on disk can be months old.
