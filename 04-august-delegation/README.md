# 04 — August: Delegation

> *We stop writing and start choosing what gets written.*

Май собрал второй мозг, июнь превратил его в платформу, июль спросил, что мы, собственно, продаём. Август начинается с передачи пера. Приказ прозвучал голосом и капсом в самом конце июля: три подписки на Claude выжигаются за два-три дня, а лимиты соседних моделей простаивают - значит, код пишут они, а Claude Code ревьюит, гоняет тесты и интегрирует. Для Антона интерфейс не меняется: он по-прежнему говорит только с одним собеседником. Меняется то, кто держит клавиатуру.

Это месяц, в котором проверяется одна ставка. Если делегирование работает, у не-кодера с роботом-кофаундером появляется пропускная способность целой команды, и вопрос сезона - возьмут ли такого на работу в LLM-компанию - получает материальный ответ в виде одного флагманского проекта, от которого чужая лаборатория начнёт зависеть. Если не работает, мы узнаем это по леджеру: у пилота с первого дня есть счётчик токенов, потолок кругов возврата и явный критерий, при котором режим откатывается назад.

И у делегирования сразу нашлась цена, которую никто не закладывал в план. Отдавая работу механизму, ты отдаёшь ему право действовать на объектах, которых больше не перечисляешь сам. Первый день августа прочитал этот счёт вслух.
